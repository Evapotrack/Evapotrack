# EvapoTrack: the plan to approve (2026-10-07)

One plan, built from every review since 2026-10-06. The evidence behind each line is in the supporting documents listed at the end. If you approve it, every recommended choice below is taken as decided.

## Goal

Ship **EvapoTrack 1.2** safely, with:
- a watering recommendation that keeps runoff on target for growing plants;
- optional photos;
- fixes for the problems found;
- a repository and website that match what is live.

**Why 1.2 must happen:** the live v1.1 recommendation under-waters a growing plant if followed. In the cannabis tests, 0–5% of hand-watered waterings were within the goal range, and the pot ran dry on most days. Revision 2 reaches 54–71% in range, never runs the pot dry, and uses about 99% of the ideal water. It is already written, but has never been compiled.

## What changed from the earlier decision list

**"Leave out of Next" moves from 1.3 into 1.2.**
- **Why:** revision 2's new data model (V2) hasn't shipped. Adding one optional field to it now keeps the v1.1 → 1.2 upgrade a simple automatic one. Adding it in 1.3 would need a third data version and another migration.
- **Benefit:** it fixes the forgotten-runoff trap (about a week of 40% runoff) from the first day.
- **Risk:** small. It is added only after the build is green, with tests, and before anything is released.

Everything else is unchanged; it is grouped into phases instead of 29 separate items.
