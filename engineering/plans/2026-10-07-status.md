## How app updates reach iPhones

| What happens | What changes |
|---|---|
| Merging into `main` on GitHub | **Only the website** (GitHub Pages publishes `main`'s `docs/`; the domain is at Namecheap) |
| Pushing to any other branch | Nothing outside GitHub |
| Archive in Xcode on the Mac → upload with your Apple Developer account → App Store Connect → submit → Apple approves → Release | **The App Store app.** Phones get it by automatic update (Wi-Fi, usually while charging) or from the App Store |

- Nothing in the repository connects GitHub to the App Store: no GitHub Actions, Xcode Cloud scripts, fastlane or similar.
- Xcode Cloud is set up in App Store Connect, not in the repository. Confirm under App Store Connect › Evapotrack › Xcode Cloud. Even when enabled, it only delivers to TestFlight; an App Store release still needs your submission and Apple's review.
- **v1.1 reached your phone** because a v1.1 build was uploaded and released through App Store Connect at some point after its code was finished (2026-03-29 to 04-01). The exact date is in App Store Connect.
- Each upload needs a higher version or build number: 1.2 (1) next.
